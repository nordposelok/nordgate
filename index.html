    Добавить на экран «Домой»

    1. 1
      Откройте ссылку в Safari

      Если пришли из мессенджера, выберите открытие во внешнем браузере.

    2. 2
      Нажмите «Поделиться»

      Кнопка с квадратом и стрелкой вверх. Затем выберите «На экран “Домой”».

    3. 3
      Добавьте Nordgate

      Если есть переключатель «Открывать как веб-приложение», включите его. Затем нажмите «Добавить».

    Откройте приложение с новой иконки при включённом интернете и дождитесь отметки «Готово без интернета».

    ПОМОЩЬ

    Как работает Nordgate

    Открытие ворот

    Нажмите «Позвонить» возле нужного въезда и подтвердите вызов. Ворота проверяют номер звонящего. При двух SIM выберите линию, номер которой внесён в систему доступа.

    Приложение не получает результат звонка. Если ворота не открылись, можно позвонить повторно или обратиться в правление ТСН.

    Подсказки рядом

    Зелёная кнопка подсказывает, что ворота находятся в пределах 100 метров. При удалении от ворот подсветка гаснет. Это подсказка, а не подтверждение открытия.

    Геопозиция обновляется только при открытом приложении. После возвращения дождитесь свежих координат. Можно звонить и без геопозиции.

    Без мобильного интернета

    После первой загрузки сохраняются интерфейс и список ворот. Для звонка нужна голосовая связь. После очистки данных сайта потребуется снова открыть приложение с интернетом.

    Ваши данные

    Геопозиция обрабатывается на телефоне и не отправляется на сервер. Настройки сохраняются на этом устройстве. Аналитика не используется. При загрузке сайта хостинг получает обычные сетевые данные, включая IP-адрес.

# Nordgate PWA

Веб-приложение для жителей Северного посёлка: список ворот, звонок на GSM-контроллер, расстояния и подсказки при приближении. Устанавливается на экран «Домой» на iPhone. Сервера приложений, регистрации и аналитики нет.

- Приложение: [nordposelok.github.io/nordgate](https://nordposelok.github.io/nordgate/).
- Исходники: [nordposelok/nordgate](https://github.com/nordposelok/nordgate).
- Проверки и публикации: [GitHub Actions](https://github.com/nordposelok/nordgate/actions).

Изменения в `main` автоматически проходят проверки и публикуются на GitHub Pages. Для установки на iPhone откройте адрес приложения в Safari и следуйте инструкции «Как установить».

## Запуск

Нужен Node.js 24 LTS и npm.

```powershell
npm ci
npm run dev
```

Для проверки установки и офлайн-режима нужна production-сборка:

```powershell
npm test
npm run build
npm run preview
```

Открыть адрес, который напечатает Vite. Офлайн-кэш включается только в production-сборке; в режиме разработки он намеренно выключен. `localhost` считается защищённым контекстом для локальной проверки. Открытие файлов двойным щелчком через `file://` не поддерживается.

Для проверки **на iPhone** нужен общедоступный HTTPS-адрес или доверенный HTTPS-тестовый сервер. HTTP-адрес компьютера в локальной сети не заменяет HTTPS для геолокации и Service Worker.

## GitHub Pages

1. Создать репозиторий для содержимого **этой папки**. Ветка публикации — `main`.
2. Отправить исходники с `package-lock.json`; не отправлять `node_modules`, `dist`, журналы и ключи Android.
3. В репозитории открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Workflow `.github/workflows/pages.yml` проверяет тесты, собирает приложение и публикует `dist`. Pull request только проверяется, без публикации.
5. Открыть адрес из выполненного задания Deploy. Для репозитория `nordgate` это обычно `https://<владелец>.github.io/nordgate/`.

Относительные пути позволяют использовать корень домена и каталог проекта без редактирования `base`. Manifest, Service Worker и запрос базы также работают относительно каталога приложения. Первый заход должен быть по URL со слешем на конце или по `index.html`; Pages автоматически перенаправляет каталог на URL со слешем.

Для собственного домена добавить `public/CNAME` с единственной строкой доменного имени и настроить DNS и HTTPS в Pages. Домен и имя репозитория в текущей версии не зафиксированы. До массовой установки желательно выбрать постоянный домен.

GitHub Free предоставляет Pages из публичного репозитория. Возможность использовать приватный исходный репозиторий зависит от тарифа. Сам опубликованный статический сайт и JSON с номерами доступны посетителям. `noindex` не является ограничением доступа.

## Vercel

Импортировать тот же репозиторий в Vercel. Файл `vercel.json` задаёт сборку `npm run build`, папку `dist` и заголовки обновления кэша. Серверные функции не нужны. Бесплатный Hobby допускает личное некоммерческое использование; для приложения ТСН соответствие условиям нужно оценивать с учётом фактического создания и сопровождения.

## Данные ворот

`public/phones.json` — проверяемая копия базы из Android. Поля: `id`, `label`, `phone`, `latitude`, `longitude`. Сейчас 7 записей; код не ограничивает количество ворот. Для номера допускается только международный формат `+` и цифры. Сборка проверяет уникальность id, координаты и номера. Версия базы — первые 8 символов SHA-256 файла, доступна в диагностике.

После изменения сверить обе базы:

```powershell
npm run check:android -- "E:/#prjw/tsn/nordgate/Resources/Raw/phones.json"
```

Команда только сравнивает файлы и ничего не меняет. Чтобы перенести изменения, осознанно скопировать актуальный JSON в `public/phones.json`, повторить проверки и выпустить новую сборку. Локальная база Android и PWA автоматически не синхронизируется.

Обновление номера, координат или интерфейса создаёт новый выпуск офлайн-кэша. Следующий онлайн-запуск обнаружит его и предложит кнопку **«Обновить»**. До применения новой версии используется предыдущая согласованная версия интерфейса и данных. Неудачная установка не удаляет старую версию.

## Поведение

- Телефонные ссылки `tel:` запускаются только по нажатию. iPhone требует системное подтверждение вызова. Приложение не наблюдает результат звонка и состояние ворот.
- Любые ворота можно набрать без разрешения геопозиции. Право открытия проверяет контроллер по номеру звонящего, а не PWA.
- На iPhone с двумя SIM житель выбирает линию с номером, внесённым в СУД. Программный выбор SIM не реализован.
- Геопозиция включается отдельным действием. Выбор запоминается локально; выключить её можно в настройках.
- Геоподсказки работают на видимой странице. События `watchPosition` дополняются резервным запросом раз в 1–600 секунд (по умолчанию 15), без одновременных резервных запросов.
- Возврат в приложение начинает новое получение координат. Поздние ответы прежнего сеанса отбрасываются.
- Координаты старше 30 секунд не подсвечивают кнопки. При погрешности более 100 м расстояния показываются приблизительно, подсветка отключается.
- Подсветка: вход в радиус 100 м; сброс после выхода за 120 м; порог тренда 25 м. Строки остаются на своих местах. Нажатие приглушает подсказку на 20 секунд, не блокируя повторный звонок.
- В настройках есть расстояния, координаты/точность и период резервного запроса. Если хранилище браузера недоступно, настройки действуют до закрытия страницы; приложение сообщает об этом.
- Офлайн-кэш содержит интерфейс, иконки и JSON. Первый запуск и получение обновлений требуют интернета. Для звонка нужна голосовая связь. Очистка данных сайта или удаление кэша системой потребуют повторной онлайн-загрузки.
- Координаты не отправляются на сервер; хостинг получает обычные сетевые запросы. Внешних шрифтов, карт, CDN и аналитики нет.

## Структура

```text
src/domain.ts              валидация, расстояния, близость, настройки
src/location.ts            получение позиции и жизненный цикл
src/main.ts                интерфейс и пользовательские действия
src/pwa.ts                 установка Service Worker и обновления
src/styles.css             адаптивный интерфейс
public/phones.json         служебные номера ворот и координаты
public/manifest.webmanifest установка на экран «Домой»
scripts/build-pwa.mjs       согласованный выпуск кэша
scripts/service-worker.js   офлайн-оболочка, без автоматического обновления
tests/                     алгоритм, жизненный цикл, офлайн-кэш
docs/iphone-pilot.md        сценарии испытаний на настоящих iPhone
```

Исходная иконка из Android сохранена в `assets/app-icon-source.png`; размеры для установки — в `public/icons`. Android-проект не изменён.

## Граница проверки

Локальные автоматические и браузерные проверки не заменяют испытания на настоящем iPhone: системный телефонный вызов, выбор SIM, разрешения Safari, установленный режим и открытие ворот требуют полевого пилота. Порядок — в [iphone-pilot.md](docs/iphone-pilot.md).
